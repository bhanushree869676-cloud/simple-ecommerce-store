# Simple E-commerce Store

## Live Website
[Visit My E-commerce Store](https://simple-ecommerce-store-pvvm.onrender.com)

## Project Description
A simple e-commerce website developed using Python Django, HTML, CSS, and JavaScript.

## Features
- Product listings
- Product details
- Shopping cart
- User registration and login
- Order processing
- Database management

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## How to Run Locally

1. Clone the repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Run migrations:

   `python manage.py migrate`

4. Start the server:

   `python manage.py runserver`

5. Open http://127.0.0.1:8000/
